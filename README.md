# LOA-AI-agent

## Ma Cuisine

Application de cuisine web (HTML/CSS/JS, sans dépendance). Ouvrir `cuisine/index.html` dans un navigateur.

- Recettes : recherche (nom ou ingrédient), catégories, favoris
- Ajout, modification, suppression de recettes
- Ajustement automatique des quantités selon le nombre de personnes
- Étapes à cocher pendant la préparation
- Liste de courses alimentée depuis une recette
- Minuteur de cuisson

Les données sont enregistrées localement dans le navigateur.
